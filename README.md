# 企业战略落地智能助手原型

Vue 3 与 Vite 构建的企业战略工作台。项目负责人进入「申报助手」对话，审批人进入「立项评审」，管理层进入「年度进展」。查规则、材料查询、延期分析和问数使用本地规则模拟。界面遵循 [UI 设计规范](./DESIGN.md)。

## 启动

在 demo 目录运行以下命令，并打开终端显示的本地地址。

~~~sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
~~~

本地模式把操作保存在当前浏览器。`npm run build` 生成 dist，可用 `npm run preview` 预览构建结果。部署至非本地地址后使用原有 WorkBuddy 共享工作区。

## 云服务

- 云服务公开配置（endpoint、publishableKey、oauthRelayBaseUrl）写在 `src/cloud.js`，均为可分发的公开值，不含密钥。
- `strategy_workspace`：共享工作区快照，一行 JSONB 加 `revision` 版本号。写入带版本号条件，两个窗口同时编辑时，后写的一方会被识别为冲突并载入云端最新数据，不会静默覆盖别人的提交。
- `strategy_activity`：申报、审批、进度、预警与结项的流转留痕，仅追加。工作台「最近流转」优先展示这里的记录。
- 操作后自动合并提交，顶栏显示「正在保存到云端 / 云端已同步」；失败时在内容区给出原因与「重试保存」。
- 首次打开若云端还没有工作区，用内置演示数据初始化一次。
- 工作区是演示用的共享空间：拿到链接的人都能读写同一份数据，不区分登录身份。需要按人隔离数据时再接入云服务身份认证。

## 校验

~~~sh
npm test              # 业务规则与云端接入层的单元测试
npm run verify:cloud  # 直连云数据库：读取、带版本号写入、冲突识别、留痕
~~~

## 演示

首次使用从项目负责人的「申报助手」开始。右上角「演示设置」切换各自独立的数据场景，角色菜单切换同一场景的项目负责人、产品线审批人和管理层。

1. **申报与补件**。选「从申报开始」。在同一对话输入「产品开发类需要哪些材料？」和「我想发起一个立项」。助手回答后继续按类型收集申请信息。要快速体验拦截，可在新对话侧栏点击「载入样例」，然后发送 `补充材料：客户确认函：客户已确认参加远程诊断模块试用。`，点击「确认送审」和「提交审批」，在对话中查看回执。手动补录可以在草稿工具中打开。文本附件支持 TXT、Markdown、CSV，其他格式可粘贴原文。最近对话在本次打开页面期间保留，可通过单条记录旁的删除按钮移除。需要刷新后继续的申请可以保存草稿。
2. **核查与人工批准**。保持当前场景，切换「产品线审批人」。在「立项评审」先阅读所选版本的申报单，展开附件查看原文，再按需点击「发起 AI 分析」，询问材料缺口、评审依据或审批前需核实的事项。点击引用可回到申报原文或企业条款。「材料核查」可查看预审明细，人工核对后在「审批决定」批准立项或退回补件。「补件评审示例」可对照 v1、v2，会话按版本保存到页面刷新前。
3. **延期**。选「执行预警示例」进入「进度与风险」，从列表点击「查看详情」，再点击「发起 AI 分析」。可先问「会影响哪些后续节点？」再追问「再具体一点」。关闭面板后，通过「继续 AI 分析」回到当前会话。点击「新建分析」从同一预警的最新数据开始，旧会话可从面板顶部的下拉框打开。会话在刷新前保留。通过回复的「查看进度记录」核对依据，从里程碑预警的「查看与分析预警」返回对应详情。也可在刚批准的项目里把客户试用验收的预计日期改为 2026-11-25（延期 5 天），再改到 2026-11-27（延期 7 天），保留实际完成日期为空。
4. **管理层问数**。选「结项问数示例」，在年度指标卡点击「AI 问数」。问「哪些项目已贡献收入？」再问「怎么算的？」，区分 21% 年度目标达成率和 70% 项目达成率。点击收入来源回到结项登记。重新打开问数面板可继续本次页面的对话。

**Demo 0.2 暂行口径**。产品开发类演示投资额、承诺收入和客户试用确认材料。技术研究类演示技术问题、创新、验证方法和复用计划，两类当前送往同一个审批人。延期分级为 6–10 天「关注」、11 天起「较高」，升级规则待确认。界面和本地业务函数按所选演示角色限制操作，生产环境需要服务端身份认证和授权。

「演示设置」中的「下次 AI 调用模拟失败」可演示失败和重试，在下一次调用后自动恢复。

改动代码后要更新线上分享链接，需重新 `npm run build` 并再次发布。
