# 企业战略落地智能助手原型

Vue 3 与 Vite 构建的企业工作台。项目、申报材料、评审记录、进度预警与结项数据保存在 WorkBuddy 云数据库，多人、多设备打开同一链接看到同一份工作区；角色切换与 AI 核查结论仍为演示逻辑。界面遵循 [UI 设计规范](./DESIGN.md)。

## 启动

在 demo 目录运行以下命令，并打开终端显示的本地地址。

~~~sh
npm install
npm run dev
~~~

npm run build 生成 dist，可用 npm run preview 预览构建结果。启动后需要能访问云服务，否则页面会停在「连接云端工作区」并给出重新连接入口。

## 云服务

- 云服务公开配置（endpoint、publishableKey、oauthRelayBaseUrl）写在 `src/cloud.js`，均为可分发的公开值，不含密钥。
- `strategy_workspace`：共享工作区快照，一行 JSONB 加 `revision` 版本号。写入带版本号条件，两个窗口同时编辑时，后写的一方会被识别为冲突并载入云端最新数据，不会静默覆盖别人的提交。
- `strategy_activity`：申报、审批、进度、预警与结项的流转留痕，仅追加。工作台「最近流转」优先展示这里的记录。
- 操作后自动合并提交，顶栏显示「正在保存到云端 / 云端已同步」；失败时在内容区给出原因与「重试保存」。
- 首次打开若云端还没有工作区，用内置演示数据初始化一次。
- 工作区是演示用的共享空间：拿到链接的人都能读写同一份数据，不区分登录身份。需要按人隔离数据时再接入云服务身份认证。

## 校验

~~~sh
npm test              # 业务规则与云端接入层的单元测试
npm run verify:cloud  # 直连云数据库：读取、带版本号写入、冲突识别、留痕
~~~

## 演示

初次打开进入工作台的「补件评审示例」。在待办点击「开始评审」，可从核查结论打开材料抽屉，也可查看历史提交及准入条款。

右上角「演示设置」可选「从申报开始」，切到项目负责人的工作台。角色菜单用于切换项目负责人、产品线审批人和管理层。

1. **申报**。在工作台点击「继续申报」，确认项目概况和里程碑，进入支持材料后提交审批。切换产品线审批人，从待办开始评审。核对「证据不足」，查看依据并填写原因退回。
2. **补件**。切回项目负责人，在待办点击「补充材料」。新增客户试用说明，例如「客户已确认参加远程诊断模块试用。」提交新版本后，切换审批人，检查依据并人工批准。
3. **延期**。切回项目负责人，进入里程碑与预警。把客户试用验收预计日期改为 2026-11-25，延期 5 天。继续改到 2026-11-27，延期 7 天并触发预警。也可从工作台的待办直达预警。查阅 AI 分析，确认措施并记录处理结果。
4. **结项**。在「结项与贡献」录入 210 万元，并填写 2026 年度确认日期与来源。切换管理层，从战略看板查看 70% 项目达成率和 21% 年度目标贡献，点击确认收入或贡献比例查看依据。

「演示设置」中的「下次 AI 调用模拟失败」可演示失败和重试，在下一次调用后自动恢复。

改动代码后要更新线上分享链接，需重新 `npm run build` 并再次发布。
